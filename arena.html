Arena allocator

Arena allocator based on gingerBill's implementation as a single-header library à la stb.

source

Usage

        #define ARENA_IMPLEMENTATION
        #include "arena.h"

        arena_t arena = {0};
        #define ARENA_SIZE 1024
        unsigned char mem[ARENA_SIZE];
        arena_init(&arena, mem, ARENA_SIZE);

        {
            char *s = arena_sprintf(&arena, "%s, %s!", "Hello", "World");
            puts(s); // Prints "Hello, World!"
        }

        arena_deinit(&arena);
